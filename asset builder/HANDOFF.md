# 3D Asset Builder — 핸드오프 문서

이 문서는 별도 대화에서 정의한 "오늘의집 3D 에셋 빌더"의 모든 결정사항·규칙·자산을
Claude Code로 이어받기 위한 컨텍스트다. 함께 전달되는 `asset-builder.html`(로컬
프로토타입)의 출발점 설명을 포함한다.

---

## 1. 목표

사용자가 **키워드 + 색상**만 입력하면, 브랜드팀이 정의한 일관된 스타일의 3D 아이콘
에셋(PNG)이 생성되는 웹툴. 프로토타입용이며, 실제 서비스 적용·고도화에는 정식 3D
에셋 파이프라인을 사용한다.

현재 단계: 로컬 단일 HTML 프로토타입(`asset-builder.html`)으로 "검색어+색상→생성"의
동작과 비용을 검증하는 중. 다음 단계는 API 키를 서버 뒤로 숨긴 팀 배포용 웹앱.

---

## 2. 핵심 아키텍처 결정 (왜 이렇게 가는가)

- 이 빌더의 생명은 **레퍼런스 이미지를 모델이 비전으로 확인하게 하는 것**이다.
  스타일 일관성이 거기서 나온다.
- Custom GPT의 Knowledge 첨부는 이미지 생성 시 비전 입력으로 들어가지 않아 실패했다.
  채팅에 이미지를 직접 첨부하거나, 외부 raw URL을 비전으로 읽혀야만 모방이 된다.
- raw URL을 채팅/지침에 넣는 방식은 모델이 매번 열어준다는 보장이 없어 불안정하다.
- 따라서 **OpenAI 이미지 API의 `images.edit` 엔드포인트에 레퍼런스 이미지를 매
  요청마다 강제로 함께 전송**하는 방식이 유일하게 안정적이다. 이것이 현재 채택안.

## 5. 생성 규칙 (프롬프트 v2.1 핵심 — 우선순위 순)

1. **형태 단순도**: 기본 기하 도형(큐브/실린더/구/원뿔/각뿔) 조합으로 단순화.
   디테일 밀도가 Reference B를 넘지 않게. 사물 식별에 필요한 최소 형태만.
2. **시점**: orthographic 아이소메트릭 강제. 원근/소실점 없음, 수직 모서리 평행,
   약 35도 부감, 카메라 롤 0, 정면샷·탑뷰 금지. (Reference B의 각도를 따름)
3. **구성**: 단일 오브젝트, 중앙 배치. 텍스트·숫자·글자·라벨·로고 금지(단순 도형
   심볼 star/arrow/heart/check/% 만 허용). 배경 투명.
4. **재질**: 매트 베이스 + 아주 약한 새틴 광택만. 강한 글로시·반사·큰 하이라이트·
   거울·플라스틱 윤기 금지. 포토리얼 텍스처 금지. 매끈한 단일 표면.
5. **색상**: 위 4번 팔레트의 세로 그라데이션.

생성 후 자가 점검(단순도/시점/텍스트/재질/색상/구성)으로 어긋나면 재생성.

전체 프롬프트 문자열 생성 로직은 `asset-builder.html`의 `buildPrompt()` 함수에
구현돼 있으니 그대로 참고/이식할 것.

## 6. OpenAI 이미지 API 사양 (2026-06 확인 기준 · 변동 가능하니 재확인 필요)

- 엔드포인트: `POST https://api.openai.com/v1/images/edits` (멀티파트 form-data)
- 모델: `gpt-image-1.5` (기본). 대안: `gpt-image-1`, `gpt-image-2` 등.
- 레퍼런스 이미지: `image[]` 필드로 여러 장 전송 가능 → A, B 두 장을 함께 보냄.
- 주요 파라미터: `prompt`, `size`(예: 1024x1024), `n`, `background`(transparent),
  `input_fidelity`(high/low — 입력 이미지 스타일 충실도, high 사용),
  `output_format`(png 기본).
- **주의: gpt-image 계열은 OpenAI 콘솔에서 Organization Verification(조직 인증)을
  완료해야 호출 가능.** 미인증 시 호출 실패.
- 주의: 일부 신모델(gpt-image-2 계열)은 transparent 배경 미지원 — 모델 바꿀 때 확인.
- 과금: 이미지 1장당 토큰 기반 소액 과금. 콘솔에서 월 usage limit 설정 권장.

## 7. 현재 프로토타입(asset-builder.html)의 상태와 한계

- 단일 HTML. 브라우저에서 열어 API 키 입력 → 키워드+색상 → 생성 → PNG 다운로드.
- 7색 팔레트 UI, 색상 라우팅, 프롬프트 빌더, 레퍼런스 2장 자동 첨부가 모두 내장됨.
- **한계: API 키를 브라우저에 직접 넣는 구조라 팀 배포 불가(키 노출).** 프로토타입
  검증 전용. 또한 브라우저에서 OpenAI로 직접 fetch 하므로 CORS/네트워크 환경에
  따라 막힐 수 있음(서버 경유가 정석).

## 8. Claude Code에서 이어서 할 일 (제안)

1. 프로토타입 동작·비용 검증(이미 됐으면 생략).
2. **백엔드 추가**: API 키를 서버 환경변수로 숨기고, 프론트는 자체 백엔드에만 요청.
   (예: Next.js API route / Express / serverless function)
3. 프론트엔드를 프레임워크로 이식(현재 HTML 로직을 컴포넌트화). 7색 팔레트·라우팅·
   프롬프트 빌더는 `asset-builder.html`에서 그대로 가져올 수 있음.
4. 호스팅(Vercel/Netlify 등)으로 팀 내부 링크 배포.
5. 옵션: 생성 이력 저장, 배경 자동 제거 후처리, 배치 생성, 즐겨찾는 키워드 프리셋,
   레퍼런스 이미지 버전 관리.

레퍼런스 이미지 자체는 `noyahjung/brand-assets` repo에 있으므로, 코드에서는 URL을
참조하거나 repo를 받아 로컬 파일로 동봉하는 방식 모두 가능.
