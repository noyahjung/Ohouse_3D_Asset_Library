# Ohouse Brand Book

> Authenticity라는 브랜드 가치를 비주얼과 언어로 풀어내고, 그 결정·자산·시선을 외부에 공개적으로 정리해 둔 브랜드 진술 시스템.

---

## 1. 시스템의 목적

### Why

- "이렇게 살아보고 싶다"는 브랜드 약속을 시각·언어로 함께 풀어내기
- 사내 매뉴얼이 충족하지 못하는 **외부 시각 정체성의 공개적 정리** 영역을 만들기
- 흩어져 있던 그래픽·언어 자산을 동일한 원칙 위에서 묶고, 그 결정의 시선까지 함께 보여주기
- 자산 제작·운영의 일관성과 확장성을 보장하는 web 형태 디자인 시스템의 토대 유지

### What

- Authenticity(진정성)이라는 브랜드 가치를 비주얼·버벌·색·심볼 네 축으로 변환하는 진술의 묶음
- 디자이너·엔지니어가 같은 언어로 작업할 수 있도록 코드·자산·가이드·인터랙션이 함께 제공되는 살아있는 라이브러리
- 매뉴얼이 아니라 *진술* — "이렇게 쓰세요"가 아니라 "우리는 이렇게 봅니다"의 결

### For Whom

| 대상 | 역할 | 어디서 만나는가 |
| --- | --- | --- |
| 사내 디자이너·엔지니어 | 자산 제작·통합 | 사내 실무 문서 (별도) |
| **동종 업계 디자이너** | 브랜드 시선 이해 | **이 브랜드 북 (1차 타겟)** |
| **입사 지원자** | 일하는 방식 파악 | **이 브랜드 북** |
| **협업 파트너** | 정체성 확인 | **이 브랜드 북** |

브랜드 북은 사내 매뉴얼의 *보조*가 아니라 *외부 진술*로 별도 위치에 자리합니다. 처방형(Do/Don't) 항목은 사내 문서로 분리하고, 외부판에는 원칙·시선·결과물만 큐레이션됩니다.

## 2. 시스템의 정의

### 정보 구조 (사이드바)

```
About
  Mission

Brand                  ← 정체성 코어
  Symbol
  Visual Principles
  Tone of Voice
  Color

Assets
  Overview
  Graphic Assets
    Icon · 2D Assets · 3D Assets · Motion(개발예정) · Pattern/Background(개발예정)
  Image Assets
    Photographic Assets
```

- About: 브랜드 북의 *왜·누구를 위해*를 선언하는 진입점.
- Brand: 브랜드 정체성의 4개 축 — 형태(Symbol)·시각(Visual)·언어(Tone of Voice)·색(Color).
- Assets: 그 결정이 실제 형태화된 자산 카탈로그. 매뉴얼이 아니라 큐레이션된 갤러리.

### 시각 자산의 분류

| 그룹 | 포맷 | 정의 | 주요 용처 |
| --- | --- | --- | --- |
| Brand | Symbol | 브랜드의 핵심 상징 단위 | 로고, 앱 아이콘 등 최상위 노출 |
| Graphic Assets | Icon | 사용자 행동·선택을 직관적으로 안내하는 벡터 그래픽 | UI 컨트롤, 안내 |
| Graphic Assets | 2D Assets (SVG) | 작은 용처에서 서비스 성격을 시각적으로 대표 | 숏컷, 카드 헤더 |
| Graphic Assets | 3D Assets (Still) | 큰 용처에서 시선을 끌고 브랜드 완성도를 강화 | 메인 비주얼, 캠페인 |
| Graphic Assets | Motion Assets (개발예정) | 행동 피드백·전환·학습 보조 | 인터랙션, 온보딩 |
| Graphic Assets | Pattern / Background (개발예정) | 화면 배경면 구성, 브랜드 결을 은은하게 깔아 밀도 보강 | 섹션 배경, 카드 후면 |
| Image Assets | Photographic Assets | 실제 상품·인테리어 신을 사실적으로 표현 | 커머스 컨텍스트 |

### 비주얼 4원칙 — Authenticity의 시각화

| 원칙 | 정서 | 의미 | 시각적 표현 |
| --- | --- | --- | --- |
| 01 Smoothing Line | 부드러움 | 브랜드 심볼의 외형을 닮은 곡선으로, 에셋에 부분적으로 풀어내는 조형적이고 부드러운 라운딩으로 표현합니다. | 모서리·면의 라운딩, 각진 단면 지양 |
| 02 Dream | 다정함 | 유저의 꿈과 영감을 담아내고, 이를 다정한 시선으로 바라보는 정서를 은은한 그라디언트를 가진 질감으로 표현합니다. | 은은한 Vertical Gradient + 몽환적인 질감 |
| 03 Clarity | 명확성 | 유저의 꿈을 분명한 현실로 실현해내는 의지를 군더더기 없는 실루엣과 단순한 매스로 표현합니다. | 군더더기 없는 명확한 실루엣, 단순한 매스 |
| 04 Stability | 안정감 | 유저의 꿈을 진중하게 실현해 나가는 자세를 표현합니다. 지면에 안정적으로 붙은 그림자와 단계별로 정돈된 에셋 구조를 통해 시각적으로 드러납니다. | 지면에 안정적으로 붙은 그림자(Ground Shadow) + 단계별로 정돈된 에셋 구조 (Icon · Asset Small · Asset Large) |

### 버벌 4원칙 — Authenticity의 언어화 (Tone of Voice)

| 원칙 | 의미 | 말의 결 |
| --- | --- | --- |
| 01 Everyday | 일상의 언어로 — 전문 용어보다 누구나 쓰는 말이 강하다. | 전문 용어·영업적 표현·군더더기 지양 |
| 02 Warmth | 다정한 거리 — 차갑지도, 무리하게 가깝지도 않은 결. | 격식 < 환대, 친근 < 진심 |
| 03 Clarity | 분명한 약속 — 모호함은 신뢰를 흐트러뜨린다. | 구체 > 추상, 약속 > 다짐 |
| 04 Encouragement | 응원하는 시선 — 안내자가 아니라, 일상을 함께 만드는 동료. | 명령 < 제안, 평가 < 응원 |

Visual·Verbal 두 축은 사이드바 Brand 카테고리 안에서 동등한 위계로 배치되어 있습니다.

## 3. 제작 과정

### Phase 1 — 3D 에셋 라이브러리 (개념 검증)

목표: Authenticity의 시각적 해석을 3D 에셋 한 종에서 시연

- Frosted material 시스템: vertical gradient + 반투명 질감으로 "Dream"을 구현
- 8종 에셋 등록: 이사박스, 쿠폰, 선물상자, 정수기, 바스켓, 시계, 카메라, 패키지박스
- 공유 머터리얼 팔레트: 색상·재질을 단일 소스(materials.js)에서 관리
- HDR 환경 + IBL: 자산이 어떤 배경에서도 일관된 라이팅으로 보이도록
- Built-in 머터리얼: Glass, Chrome, Lens Glass, Camera Lens — 특수 표현용

### Phase 2 — 시스템화 (재사용성 확보)

목표: 단일 자산을 넘어 자산군이 같은 규칙으로 작동

- Asset registry 패턴: 에셋마다 materialFor, gradientYShift, frameScale, yOffset/zOffset, modelScale 등 선언적 규칙 (Coupon modelScale 1.5 — 바디 크기 정규화 사례)
- HARMONY 색상 시스템: 바디 컬러마다 짝지어진 Accent 컬러가 자동으로 따라옴
- HARMONY 2 도입: 기존 harmony보다 10% 어두운 보조 색상 — 리세스/안쪽 면 같은 미세 위계 표현
- Designer-preset 카메라 뷰: 자산별 3개 추천 앵글 저장 → 디자이너가 의도한 프레이밍으로 즉시 출력
- Black Friday 모드: 시즌성 머터리얼을 단일 토글로 전체 라이브러리에 적용

### Phase 3 — 운영·출력 파이프라인

목표: 자산을 만든 후 빠르게 산출물로 변환

- PNG 2-pass export: 실루엣 + 일반 렌더 합성으로 어떤 배경 위에도 깔끔한 불투명 출력
- 라이브러리 썸네일 시스템: 정적 PNG 우선 + 라이브 렌더 폴백
- Contact-AO shadow: 직사 그림자에 max() 합성으로 접지면 헤일로 제거 (bevelComp 수동 튜닝 대체)
- Auto-optimize 파이프라인: 새 에셋 업로드 시 `gltfpack -kn -km` 자동 실행, 50–80% 용량 절감
- De-interleave + GLB 변환: C4D 인터리브 버퍼 분리, 미사용 NORMAL/UV 제거 → 카메라 에셋 832KB → 393KB (52.8%↓)

### Phase 4 — Visual System Shell (디자인 시스템화)

목표: 자산·가이드·도구를 단일 웹 라이브러리로 통합

- 라이브러리 셸 (v1): 헤더 + 사이드바 + 페이지 네비게이션 골격, 사이드바 위계는 Symbol → Graphic Assets(5종) → Image Assets(Photographic) 3단 구조로 정돈
- Visual Language 페이지(v1): Smoothing Line → Dream → Clarity → Stability 4원칙을 16:9 인터랙티브 시퀀스로 안내 (랜딩)
- Principles 모듈 분리: 슬라이드 콘텐츠를 `principles/slides.js`로 추출 — 본 라이브러리와 walkthrough 콘텐츠를 분리해 유지보수 단순화
- 재질(Variants) 모드: `?mode=variants` — A~E재질 × Blue/Red 슬롯에서 5에셋을 동시에 비교하며 머티리얼 튜닝, hex 입력·per-slot 기본값 저장·PNG 일괄 export·그림자 On/Off 토글 지원
- 3D 커스터마이저 진입: 디자이너가 컬러·각도를 변경해 즉시 PNG로 추출
- Cloudflare Workers 배포 경로 추가: `wrangler.toml` + pass-through Worker로 정적 자산 바인딩

### Phase 5 — Brand Book 전환 (외부 진술화) — *현재 진행*

목표: 사내 매뉴얼 톤이 묻어나던 v1 라이브러리를 외부 statement에 맞는 *Brand Book*으로 재구성

#### 5.1 포지셔닝 전환

- v1을 동결된 참조로 두고 `v2/` 폴더에서 새 구조로 재출발
- 명칭 변경: **Visual Asset Library → Brand Asset Library → Brand Book** — 카탈로그가 아닌 출판물의 결로 정렬 (Netflix·Airbnb 브랜드북 어휘 참조)
- 처방형 Do/Don't 블록 제거 — 외부 관람자가 "이걸로 뭔가 만들 사람"이 아니라는 전제 정립
- 루트 `index.html`을 v2로 가는 메타-리프레시 redirect로 교체. 3D 라이브러리의 `← Library` 뱃지도 v2 홈으로 갱신

#### 5.2 정보 구조 재설계 (여기어때 디자인 라이브러리 패턴 참조)

- 사이드바를 About → Brand → Assets 3단으로 재구성. Symbol은 Asset 카테고리에서 Brand 위계로 승격
- 새 페이지 신설:
  - **About** (`v2/index.html`) — Mission. 외부 진술의 진입점
  - **Symbol** (`v2/symbol.html`) — 브랜드 정체성의 출발점
  - **Visual Principles** (`v2/visual-principles.html`) — 기존 Visual Language의 4원칙 콘텐츠 + iframe walkthrough 합본
  - **Tone of Voice** (`v2/tone-of-voice.html`) — 신규. Everyday/Warmth/Clarity/Encouragement 4원칙 + 톤 예시 카드
  - **Color** (`v2/color.html`) — 신규. 무드보드형 모션 스테이지 + placeholder 원칙 4개
  - **Overview** (`v2/overview.html`) — v1 콘텐츠를 v2 셸로 재서빙

#### 5.3 페이지 디자인 통일

- Brand 카테고리 4개 페이지가 모두 동일한 16:9 hero footprint로 오픈 (content-max 800px, soft border, 12px radius)
  - About: 정적 풍경 이미지 (박공 지붕 + 노을)
  - Symbol: 심볼 마크
  - Visual Principles: iframe walkthrough (자동 재생)
  - Tone of Voice: 정적 풍경 이미지 (편지 쓰는 손)
  - Color: 모션 스테이지 (적층식 무드보드)
- 본문 텍스트 폭을 hero 이미지와 동일하게 정렬 (기존 640–680/720px 캡 제거 → `content-max`까지)
- Typography 정렬: `principle-row-body h3` 26→24px (`about-section h3`과 일치)

#### 5.4 자산 페이지 재구성

- 별도 Overview 섹션 제거, 페이지 hero가 곧 Overview (eyebrow + h1 + lead)
- Showcase 갤러리: 가변 사이즈(`is-wide`/`is-tall`) 폐기 → 5×2 = 10개 균일 1:1 placeholder. `<img>` 슬롯 교체 패턴을 HTML 주석으로 안내
- Form Principles (구 "조형의 결") 섹션 구조 재설계:
  - 카드형 2×2 그리드 → 풀폭 2-컬럼 행 스택
  - 각 행: 좌측(title + 32px 구분선 + 본문) / 우측(이미지 placeholder, 4:3)
  - hairline divider, 배경 카드 제거
- 4원칙은 자산별로 *고유한* 결정으로 큐레이션 (브랜드 4원칙을 강제 매핑하지 않음)

#### 5.5 Color 페이지 모션 스테이지

목표: 색에 대한 *관점*을 정적인 팔레트가 아닌 움직이는 무드보드로 보여주기

- 11개 요소(5 photo + 6 color chip)가 차곡차곡 적층되며 `guide.png` 구도로 빌드업
- Layer 위계: photo z-index 1, color chip z-index 10 — 칩이 사진에 절대 가려지지 않음
- Entry: translateY(28→0) + opacity 페이드인, 0.1→2.6초 staggered
- 정착 후: 5px Y 오실레이션, 요소마다 phase 오프셋 → "둥실둥실"
- DOM 분리: outer = positioning + entry, inner = continuous float (두 transform이 충돌하지 않음)
- `prefers-reduced-motion` 대응

#### 5.6 Visual Principles iframe 안정화

- 부모-자식 postMessage 핸드셰이크가 콜드 로드에서 race condition을 일으켜 첫 진입 시 빈 박스 상태로 멈추던 문제 발견
- iframe 자가-reveal 패턴으로 전환: `openPrinciples()`가 슬라이드 0 promise를 반환 → embed 부트스트랩에서 `.then(reveal)` 체이닝
- 3초 safety timeout + 레거시 `principles:start` 메시지 호환성 유지

#### 5.7 이미지 파이프라인 & 배포

- 모든 hero·section 배너를 WebP로 일괄 변환 (RGBA 알파 미사용분은 RGB로 drop):
  - bg.png 1.7MB → bg.webp **59KB** (96.7%↓)
  - about1–3.png 평균 3.1MB → .webp **~150KB** (95%↓)
  - text.png 2.8MB → text.webp **94KB** (97%↓)
  - color_pic1–5.png 합계 2.7MB → .webp **210KB** (92%↓)
  - symbol.png 15KB → symbol.webp **7KB** (52%↓)
- GitHub Pages 배포: `feat/visual-system-shell` 브랜치 루트, 자동 빌드
- 공유 URL: **<https://noyahjung.github.io/Ohouse_3D_Asset_Library/>** (루트가 v2로 자동 리다이렉트)
